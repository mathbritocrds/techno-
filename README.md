 Este projeto tem como objetivo desenvolver um sistema computacional voltado à gestão industrial, com foco na análise de custos de produção, controle de jornada de trabalho e apoio à tomada de decisão gerencial. A proposta surge a partir da observação prática de processos produtivos em uma indústria de grande porte. O sistema permitirá o registro e análise de dados como consumo de matéria-prima, impostos, custos operacionais e lucro gerado, além de integrar funcionalidades de controle de ponto eletrônico. A solução visa contribuir para maior eficiência operacional e melhor gestão de recursos.
